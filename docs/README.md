# Documentation

## Using Heliograph

The guides are in [skills](skills/README.md): each is read by people, loaded by agents as a skill,
and served to agents over MCP, from one file.

| | For | |
|---|---|---|
| [authoring-with-an-agent](skills/authoring-with-an-agent/SKILL.md) | Authors, agents, developers | What an agent can do over MCP, how the work goes, and how a developer turns it on |
| [writing-a-template](skills/writing-a-template/SKILL.md) | Authors | How to write a template: tags, conditions, where they work, what is refused |
| [using-heliograph](skills/using-heliograph/SKILL.md) | Developers | The dictionary, compile and render, diagnostics, what the library guarantees and what you must do |
| [diagnostics](skills/diagnostics/SKILL.md) | Both | Every diagnostic code: what it means and what to do about it |
| [third-party.md](third-party.md) | Both | Other people's software Heliograph touches, its licences, and why Heliograph stays MIT |
| [edge-cases.md](edge-cases.md) | Both | Every way a template can go wrong that has been thought of: what happens, and whether it is built |
