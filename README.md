# Heliograph

Write outgoing correspondence in the word processor you already use, and render it for every
channel you send on: post, PDF, email and text.

A heliograph sent messages by flashing sunlight across long distances. This one sends one piece
of correspondence out across many channels.

Content designers write in Word, Microsoft 365 or LibreOffice, with nothing installed. A
dictionary says what a template may use, and a compiler says what is wrong, and where, before
anything is sent. Everything a person can do, an AI agent can do the same way.

Heliograph renders; it does not deliver. Your system, or a host such as
[Wayfinder](https://github.com/jonnymuir/Wayfinder), sends what Heliograph produces through
whichever provider it uses.
