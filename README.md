# Heliograph

Compose outgoing correspondence once, and render it for any channel: email, SMS, messaging apps,
PDF and print.

A heliograph sent messages by flashing sunlight across long distances. This one sends a single
message out across many channels.

Heliograph renders; it does not deliver. Your system, or a host such as
[Wayfinder](https://github.com/jonnymuir/Wayfinder), sends what Heliograph produces through
whichever provider it uses.

> **Status:** early design. Nothing is published yet. See the
> [design brief](https://github.com/jonnymuir/Heliograph/blob/main/docs/brief.md).
